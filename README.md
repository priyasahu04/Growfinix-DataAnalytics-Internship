## ✅ Task 2: Sports Analytics & Performance Metrics (SQL)
### Description
Extracted insights from a massive relational database containing Indian Premier League (IPL) match history.  
Focused on **Kolkata Knight Riders (KKR)** performance across different stadiums.

### Tech Stack
- PostgreSQL / MySQL
- SQL concepts: `JOIN`, `GROUP BY`, `Window Functions`

### Objectives
1. Calculate **historical win rates** of KKR across stadiums.  
2. Compute **average run rates** of KKR by venue.  
3. Use **window functions** to analyze seasonal and cumulative win rate trends.

### Deliverables
- SQL scripts (`task2_queries.sql`)  
- Documentation (`README.md`)  
- Screenshots of query outputs (`/screenshots`)
